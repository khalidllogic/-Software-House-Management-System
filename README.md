# Software House Management System

## 📌 Project Overview

This project aims to design and build a centralized, integrated database system for a software company to manage its core operations, including:

- Managing clients, contracts, and technical support tickets.
- Tracking the software project lifecycle, implementation phases, budgets, and meetings.
- Managing software tasks and assigning them to employees, while tracking the technologies and programming languages used.
- Managing human resources, departments, job roles, salary scales, attendance records, and notifications.
- Managing quality assurance testing, software bugs and bug reports, and software releases.
- Managing the comprehensive financial and administrative system, including invoices, payments, and expenses.

---

## 🏗️ Database Engineering Structure

- **Total Number of Tables:** 24 main, supporting, and associative tables.
- **Normalization Level:** Fully compliant with **Third Normal Form (3NF)** to minimize data redundancy and prevent update, insertion, and deletion anomalies.
- **Constraints Applied:** Strict use of **Primary Keys (PKs), Foreign Keys (FKs), UNIQUE constraints, and NOT NULL constraints**.

---

## ⚙️ Execution Guide

To successfully run and import the database system in **Oracle APEX**, follow these steps:

1. Open **SQL Commands** in your Oracle APEX database account.
2. Execute the table creation and relationship script (**DDL**).
3. Execute the test/sample data insertion script (**DML**) to ensure that each table contains at least **5 records**.
4. Execute the scripts for creating **Views**, advanced queries, different types of **JOINs**, and **Subqueries**.
